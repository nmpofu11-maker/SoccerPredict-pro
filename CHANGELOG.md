# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0-repaired] - 2026-09-30

### Summary
Stable repaired baseline of SoccerPredict Pro.

### Features
- React 19 frontend with Vite
- Express.js backend with Node.js
- Capacitor for mobile support (Android)
- Google GenAI integration
- Tailwind CSS styling with Lucide React icons
- PDF parsing capabilities
- Chart visualization with Recharts
- Scheduled tasks with node-cron

### Fixed
- Core application stability
- Build pipeline optimization with esbuild
- TypeScript strict mode compatibility

### Tech Stack
- **Frontend**: React 19, Vite, TypeScript
- **Backend**: Express.js, Node.js >=22
- **Styling**: Tailwind CSS 4
- **Mobile**: Capacitor (Android)
- **AI**: Google GenAI
- **Data Processing**: PDF Parse, Cheerio
- **Visualization**: Recharts
- **UI Components**: Lucide React
